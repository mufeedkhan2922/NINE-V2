# NINE V2.4

This release is built on the clean NINE V2.3 checkpoint `94072c2`.

## Included

1. Real-time market feed status and stale-data gating.
2. Multi-timeframe direction confirmation inside the orchestrator.
3. Existing Chartist/SMC engine retained and used as the technical layer.
4. Atlas economic-calendar context in addition to news context.
5. Sentinel V2.4 execution gate with exposure, drawdown, daily-loss and data-freshness checks.
6. NINE dashboard/stream payloads now expose feed, runtime and order state.
7. Live broker execution is explicitly admin-only and remains disabled unless `NINE_LIVE_TRADING_ENABLED=true`.
8. Expanded Sentinel automated tests.
9. Runtime safety/health reporting.

## Safety

Live execution remains OFF by default.

No provider data is fabricated. When market data cannot be validated, trading is blocked.

## Verification

```bash
npm test

```
