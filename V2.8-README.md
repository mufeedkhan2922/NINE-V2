# NINE V2.9 — Reliability & Professional Market Workstation

V2.9 is the professional market workstation built on the V2.7.1 safety baseline.

## Workstation features

- Interactive OHLC candlestick chart
- 1m / 5m / 15m / 1h local candle views from validated candle data
- Scroll-to-zoom and drag-to-pan
- OHLC + volume hover tooltip
- Volume panel
- Crosshair
- Current-price marker
- Session boundary markers based on the existing UTC session model
- Liquidity reference levels
- Session high/low levels
- Fair-value-gap zones
- Order-block zones
- MSS marker when the validated Chartist state provides one
- Explicit LIVE VALIDATED DATA vs LAST VALIDATED DATA state
- Responsive chart layout for desktop, tablet and mobile
- Premium light trading-terminal styling

## Safety preserved

This upgrade is presentation/workstation focused. It does not enable live trading, bypass Sentinel, fabricate market data, or change the execution gate.

If market data is stale, disconnected or otherwise unsafe, the chart continues to identify the data as last validated context and execution remains blocked by the existing safety architecture.

## Reliability fixes

- Backtest replay uses validated historical candle data directly instead of requiring a full live market snapshot.
- A validated in-memory candle cache may be reused for historical replay when the live feed is temporarily stale.
- Backtest results expose reconciled initial/final balance and drawdown fields for the UI.
- Backtest failures are shown explicitly with retry controls instead of silently leaving an empty workstation.
- Signal/audit state remains visible during market-feed failures with an explicit MARKET_DEGRADED event.
- SSE market failures use a dedicated `market_error` event so they do not collide with the browser's native EventSource error event.
- Runtime/version reporting is consistently V2.9.1.
