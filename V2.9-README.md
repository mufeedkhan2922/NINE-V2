# NINE V2.9 — Full Functionality Milestone

V2.9 focuses on end-to-end reliability rather than visual changes.

## Included
- Shared/cached market-data pipeline with quote throttling and stale-cache diagnostics
- XAUUSD and NSE session-state handling
- Historical candle endpoint and expanded backtest history
- Technical/SMC backtest execution and result reconciliation
- Signal lifecycle and degraded-feed states
- Atlas news + economic-calendar diagnostics
- NINE Brain → Sentinel → paper execution gate
- Paper execution lifecycle and persisted ledger
- Provider failure/recovery diagnostics
- Symbol-aware APIs for XAUUSD/NIFTY/BANKNIFTY
- System health diagnostics
- End-to-end regression coverage

## Required external data
NINE does not fabricate market, news, or economic data. Configure `TWELVE_DATA_API_KEY` for market/history data and `FINNHUB_API_KEY` for Atlas. Availability, plan entitlements, exchange coverage, rate limits, and symbol mappings remain provider-dependent. Twelve Data documents API-key authentication, rate limits, WebSocket/REST market data, and symbol discovery; its India exchange page identifies NSE coverage.

## Safety
Live trading remains hard-locked unless the exact runtime confirmation and broker gateway configuration are present. Stale, suspicious, incomplete, or disconnected market data cannot authorize paper/live execution.
