# NINE V2.9.1 — Change Log

## Provider reliability

- Added shared in-flight deduplication for live snapshots, timeframe downloads and quotes.
- Added a conservative local Twelve Data request budget (`NINE_PROVIDER_MAX_REQUESTS_PER_MINUTE`, default `7`).
- Added HTTP 429 detection and cooldown using `Retry-After` when supplied.
- Added provider health telemetry: requests/minute, budget, cooldown, quote-cache age and last error.
- Increased quote cache to 30 seconds and live snapshot cache to 10 seconds by default.
- During provider cooldown, NINE reuses previously validated candles rather than creating a retry storm.
- Backtests reuse validated cached candles when the minimum dataset is already available, and fall back to cache when the provider is rate-limited.

## Atlas

- Increased Atlas news/calendar cache durations.
- Exposes the underlying provider error in the Atlas UI instead of showing only a generic unavailable state.

## Safety

- Rate-limited or degraded provider state blocks execution.
- Sentinel remains an independent hard gate.
- Live broker remains locked by the existing V2.9 safety requirements.
- No fabricated market, news or calendar data was introduced.

## Version

- Application: `0.2.9.1`
- Runtime: `2.9.1`
