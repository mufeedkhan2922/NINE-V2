# NINE V2.7.1 — Feed Safety & Chart Stabilization

This is a focused stabilization pass on the V2.7 Command Center.

## Changes

- Replaces the misleading connected line chart with a candlestick chart.
- Clearly labels charts as `LIVE VALIDATED DATA` or `LAST VALIDATED DATA`.
- Makes stale/degraded/reconnecting feed state visible at the top of the desk and in the hero panel.
- Keeps last validated candles visible for context while explicitly preventing users from interpreting them as live execution data.
- Adds an explicit Atlas unavailable state when validated headlines are not available.
- Preserves the existing Sentinel hard gate and paper-only execution architecture.

## Safety rule

No UI change in this patch authorizes live trading. Stale, suspicious, disconnected, or otherwise blocked market data remains non-tradable.

## Apply

Extract this bundle at the project root. It contains complete replacement files only; do not merge snippets manually.

After extraction run:

```bash
npm test
npm run build
git diff --check
git status
```
