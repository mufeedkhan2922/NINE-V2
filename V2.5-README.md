# NINE V2.5 — Intelligence Desk

V2.5 is the coordinated intelligence and production-safety upgrade built on the V2.4 checkpoint.

## Included

1. Market-data provider abstraction with timeout, validation, caching, quote/candle source tracking, and SSE delivery.
2. Chartist confluence model with liquidity, sweeps, FVGs, order blocks, MSS/CHoCH, sessions, and higher-timeframe alignment.
3. Atlas news and economic-calendar layer with source status and freshness metadata.
4. Sentinel 2.5 risk gate with stale-feed protection, geometry validation, daily-loss, drawdown, exposure, open-position, and consecutive-loss controls.
5. NINE orchestrator combining Atlas, Chartist, and Sentinel into one structured decision.
6. Live dashboard showing feed health, risk state, macro events, setup geometry, and paper positions.
7. Protected command, paper, backtest, login, and live execution APIs with rate limiting and same-origin checks.
8. Expanded automated test suite including runtime safety and rate limiting.
9. Production hardening through security headers, timeouts, overlap protection, audit events, and a two-factor environment lock for live execution.

## Safety

- No fabricated market prices are generated.
- Missing or stale market data blocks execution.
- Sentinel approval is required before execution.
- Live trading is disabled unless `NINE_LIVE_TRADING_ENABLED=true`, `NINE_LIVE_TRADING_CONFIRMATION=I_UNDERSTAND_LIVE_TRADING`, and broker credentials are configured.
- Live broker execution is restricted to an authenticated ADMIN user.
- Paper trading remains the default execution mode.

# NINE V2.6 — Autonomous Trading Intelligence

V2.6 adds a coordinated intelligence layer over the V2.5 safety architecture: multi-timeframe alignment, setup lifecycle, NINE Brain decisions, market-health gating, risk telemetry, signal events, and a V2.6 replay/backtest endpoint. Live trading remains disabled by default and Sentinel remains the execution gate.

## Safety invariants
- No validated live data -> no execution.
- Stale/suspicious data -> blocked execution.
- Incomplete setup -> no execution.
- Sentinel rejection -> no execution.
- V2.6 backtesting uses historical candles and does not place orders.
