# NINE V2.9.3

V2.9.3 is a small corrective release on top of V2.9.2. It preserves test-database isolation and fixes the TypeScript test bootstrap by relying on the Node.js type definitions already configured in `tsconfig.test.json`.

Run:

```bash
npm test
npm run build
git diff --check
```

Your existing `.env.local` is not included or modified by this bundle.
