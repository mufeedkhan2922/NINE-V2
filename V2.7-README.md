# NINE V2.7 — Command Center

NINE V2.7 is a coordinated UI and API upgrade on top of the verified V2.6 intelligence/safety core.

## Included

- Professional NINE Command Center UI
- Multi-symbol dashboard: XAUUSD, NIFTY, BANKNIFTY
- Real-time SSE market stream with symbol selection
- Chartist market-structure workstation
- Atlas macro/news intelligence panel
- Sentinel risk-control center
- V2.7 backtest/replay workstation
- Signal and audit event stream
- Session command history
- Voice command support where the browser provides SpeechRecognition
- Protected V2 backtest endpoint
- Symbol-aware analysis/dashboard/stream endpoints
- V2.7 runtime/version metadata
- Responsive desktop/tablet/mobile layout

## Safety

- Paper execution remains the active execution mode.
- Live trading remains disabled unless the existing explicit environment confirmation and broker gateway requirements are satisfied.
- NINE Brain does not override Sentinel.
- Stale, suspicious or unavailable market data remains non-tradable.
- The UI never fabricates market, news, or backtest values; unavailable values render as `—` or an explicit unavailable state.
