# NINE V2.9.2 — Test Database Isolation

V2.9.2 keeps the V2.9.1 provider-reliability improvements and fixes test/database isolation.

## What changed

- `npm test` now runs against `.nine-test-data/nine.db`.
- The test database is deleted and recreated at the beginning of every test process.
- Production `.nine-data/nine.db` is never used by the test suite.
- SQLite WAL/SHM state from a previous test run cannot contaminate the next run.
- `.nine-data/` and `.nine-test-data/` are ignored by Git.
- The shipped source bundle contains no SQLite database file.
- Runtime version is `2.9.2`.
