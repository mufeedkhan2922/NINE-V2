# NINE V2.9.2

## Database/test isolation

- Fixed `npm test` failures caused by a malformed persistent SQLite database.
- Added a dedicated test-process bootstrap that sets `NINE_DB_PATH` before any trading database module is imported.
- Test runs start from a clean `.nine-test-data/nine.db`.
- Added `.nine-data/` and `.nine-test-data/` to `.gitignore`.
- Removed the accidental SQLite database from the distributable source bundle.
- Preserved all V2.9.1 provider reliability, rate-limit protection, caching, and request deduplication behavior.
